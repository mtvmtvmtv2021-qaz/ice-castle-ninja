# こおりの城のニンジャ（ICE CASTLE NINJA）

ブラウザで遊べる3Dアクションゲームです。ニンジャになって、こおりの城の天守（てっぺん）をめざそう！

## あそびかた

| 操作 | キー |
|---|---|
| 移動 | WASD ／ 矢印キー |
| ジャンプ | Space（空中でもう一度押すと2段ジャンプ） |
| カベキック | カベにふれたまま Space |
| カギ爪ロープ | 青いクリスタルの近くで E ／ クリック |
| カメラ | マウス（画面をクリックで固定）／ J・L キー |
| やり直し | R（チェックポイントへ戻る） |
| 音のオン/オフ | M |

スマホ・タブレットでは、画面左側をドラッグして移動、右側をドラッグしてカメラを回します。「ジャンプ」と「フック」のボタンもあります。

## ステージ

1. ジャンプの足場
2. ツルツルすべる氷の床
3. カベキックで登るたてあな
4. くずれる氷と動く足場
5. カギ爪ロープで谷をこえる
6. トゲとつららの橋 → 天守へ！

かくれた巻物が5つあります。ぜんぶ見つけられるかな？
